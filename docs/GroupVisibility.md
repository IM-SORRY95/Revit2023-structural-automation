# 그룹별 부재 보기

## 1. 기능 개요

Revit 모델에 배치된 모델 그룹을 유형별로 조회하고,
사용자가 선택한 그룹과 해당 그룹의 구성요소만 현재 뷰에
임시로 표시하는 기능입니다.

여러 그룹 유형을 동시에 선택할 수 있으며,
그룹 이름과 배치된 층 정보를 이용해 검색할 수 있습니다.

본 기능은 모델 요소를 삭제하거나 영구적으로 숨기지 않고,
Revit의 임시 숨기기·분리 기능을 사용하여 표시 상태만 변경합니다.

---

## 2. 개발 배경

반복되는 구조 부재나 계단실, 코어, 기준층 부재는
Revit 모델 그룹으로 구성되는 경우가 많습니다.

기존에는 특정 그룹만 검토하기 위해 다음 작업을 반복해야 했습니다.

- 프로젝트 브라우저 또는 화면에서 그룹을 직접 찾기
- 같은 유형의 그룹 인스턴스를 일일이 선택하기
- 그룹에 포함된 구성요소를 확인하기
- 다른 부재를 임시로 숨기거나 분리하기
- 검토 후 표시 상태를 다시 원복하기

그룹 수가 많거나 비슷한 이름의 그룹이 여러 개 존재하면
원하는 그룹을 찾고 검토하는 데 시간이 오래 걸렸습니다.

이러한 반복 작업을 줄이기 위해
모델 그룹을 유형별로 정리하고 검색·복수 선택하여
관련 구성요소만 표시하도록 기능을 구성했습니다.

---

## 3. 주요 기능

### 3.1 모델 그룹 유형 수집

현재 Revit 문서에 배치된 모델 그룹 인스턴스를 수집합니다.

뷰 전용 상세 그룹은 제외하고,
실제 모델에 배치된 모델 그룹만 처리합니다.

동일한 그룹 유형의 인스턴스는 하나의 항목으로 묶어 표시합니다.

각 항목에는 다음 정보가 표시됩니다.

- 그룹 유형명
- 배치된 인스턴스 수
- 그룹이 배치된 주요 층

표시 예시는 다음과 같습니다.

```text
계단실-A  (5개) · B2F, B1F, 1F
코어-B  (12개) · 2F, 3F, 4F 외 9개 층
```

### 3.2 여러 그룹 동시 선택

한 개 이상의 그룹 유형을 동시에 선택할 수 있습니다.

선택한 그룹 유형에 해당하는 모든 인스턴스와
각 그룹의 구성요소를 함께 표시합니다.

예시:

- 계단실-A와 계단실-B 동시 검토
- 여러 코어 그룹 동시 검토
- 기준층 그룹 여러 유형 비교
- 구조 부재 그룹과 가설 부재 그룹 동시 검토

### 3.3 그룹 검색

그룹 유형명과 층 요약 정보를 대상으로 검색합니다.

검색어를 띄어쓰기, 쉼표 또는 세미콜론으로 구분하여
여러 조건을 동시에 입력할 수 있습니다.

입력한 검색어가 모두 포함된 항목만 표시됩니다.

예시:

```text
계단실
```

```text
계단실 B1F
```

```text
코어 101동
```

### 3.4 검색 중 선택 상태 유지

검색어를 변경하여 화면에 표시되는 그룹 목록이 달라져도
이미 선택한 그룹 유형은 계속 유지됩니다.

예를 들어 다음과 같이 사용할 수 있습니다.

```text
1. "계단실" 검색
2. 계단실-A 선택
3. "코어" 검색
4. 코어-B 선택
5. 선택 그룹 보기 실행
```

위와 같이 서로 다른 검색 결과에서 선택한 그룹도
최종 적용 대상에 함께 포함됩니다.

### 3.5 검색 결과 전체 선택

현재 검색 결과에 표시된 그룹 유형을
한 번에 모두 선택할 수 있습니다.

검색어를 입력한 상태에서 실행하면
검색 조건에 맞는 항목만 선택됩니다.

### 3.6 전체 선택 해제

현재 검색 결과에 관계없이
지금까지 선택한 모든 그룹 유형을 해제합니다.

### 3.7 중첩 그룹 처리

선택한 그룹 내부에 다른 모델 그룹이 포함되어 있으면
중첩 그룹과 중첩 그룹의 구성요소도 함께 수집합니다.

동일한 그룹이 여러 경로에서 반복 참조되더라도
중복 처리를 방지합니다.

### 3.8 선택 그룹 임시 표시

선택한 그룹 인스턴스와 구성요소를 수집한 뒤
Revit의 임시 분리 기능으로 해당 요소만 표시합니다.

현재 뷰에서 숨김 제어가 불가능한 요소는 제외합니다.

### 3.9 전체 원복

`전체 보이기 · 원복` 버튼을 누르면
이 기능에서 적용한 임시 숨기기·분리 상태를 해제합니다.

기존에 사용자가 영구적으로 숨긴 요소나
뷰의 다른 표시 설정은 변경하지 않습니다.

### 3.10 예외 상황 안내

다음 상황에서는 사용자에게 안내 메시지를 표시하고
실행을 중단합니다.

- 열려 있는 Revit 문서가 없는 경우
- 활성 뷰가 없는 경우
- 뷰 템플릿에서 실행한 경우
- 일람표 또는 시트 뷰에서 실행한 경우
- 현재 문서에 모델 그룹이 없는 경우
- 사용자가 그룹을 선택하지 않은 경우
- 선택한 그룹 인스턴스를 찾지 못한 경우
- 현재 뷰에서 표시할 수 있는 구성요소가 없는 경우

## 4. 처리 흐름

```text
기능 실행
→ 활성 Revit 문서 및 뷰 확인
→ 현재 문서의 모델 그룹 인스턴스 수집
→ 동일한 그룹 유형별로 인스턴스 분류
→ 그룹 유형명, 인스턴스 수, 층 요약 생성
→ 그룹 검색 및 복수 선택창 표시
→ 선택한 그룹 유형의 모든 인스턴스 수집
→ 그룹과 구성요소 수집
→ 중첩 그룹 구성요소 재귀 탐색
→ 현재 뷰에서 표시 가능한 요소 확인
→ 선택 요소 임시 분리
```

원복 실행 흐름은 다음과 같습니다.

```text
전체 보이기 · 원복 선택
→ 현재 뷰의 임시 숨기기·분리 상태 확인
→ 임시 뷰 모드 해제
→ 기존 뷰 상태로 복귀
```

## 5. 그룹 목록 구성 방식

### 5.1 모델 그룹 수집

현재 문서에서 `Group` 요소를 수집합니다.

다음 조건을 만족하는 그룹만 사용합니다.

- 요소 유형이 아닌 실제 배치 인스턴스
- 뷰 전용 요소가 아닌 모델 그룹
- 유효한 그룹 유형을 가진 그룹

### 5.2 그룹 유형별 분류

각 그룹 인스턴스의 그룹 유형 ID를 기준으로 분류합니다.

동일한 유형의 그룹 인스턴스는 하나의 옵션 항목으로 표시하며,
해당 유형의 전체 인스턴스 수를 함께 제공합니다.

### 5.3 그룹 레벨 확인

먼저 그룹의 직접적인 `LevelId`를 확인합니다.

유효한 레벨을 찾지 못하면 다음 순서로 높이를 확인합니다.

1. 그룹 위치점의 Z값
2. 그룹 Bounding Box의 최저 Z값

확인한 높이와 가장 가까운 Revit 레벨을 찾아
그룹이 배치된 층으로 표시합니다.

### 5.4 층 요약

그룹 유형이 배치된 층이 3개 이하인 경우
모든 층 이름을 표시합니다.

```text
B2F, B1F, 1F
```

배치 층이 3개를 초과하면
앞의 3개 층과 나머지 층 수를 요약하여 표시합니다.

```text
1F, 2F, 3F 외 12개 층
```

## 6. 그룹 구성요소 수집 방식

선택한 그룹 유형에 해당하는
모든 그룹 인스턴스를 먼저 수집합니다.

각 그룹에 대해 다음 요소를 표시 대상에 추가합니다.

1. 그룹 인스턴스 자체
2. 그룹에 직접 포함된 모델 요소
3. 그룹 내부의 중첩 그룹
4. 중첩 그룹에 포함된 모델 요소

중첩 그룹은 동일한 그룹을 반복 방문하지 않도록
처리한 그룹 ID를 별도로 기록합니다.

현재 뷰에서 숨김 또는 분리 제어가 가능한 요소만
최종 표시 대상에 포함합니다.

## 7. 검색 방식

검색 대상 문자열은 다음 정보를 결합하여 구성합니다.

```text
그룹 유형명 + 층 요약
```

검색어는 다음 문자를 기준으로 분리됩니다.

- 공백
- 탭
- 쉼표
- 세미콜론

분리된 모든 검색어가 대상 문자열에 포함되어야
검색 결과에 표시됩니다.

영문 대소문자는 구분하지 않습니다.

그룹 수집, 구성요소 탐색 및 표시 적용을 담당합니다.

주요 역할:

주요 역할:

- 검색 결과 전체 선택
- 전체 선택 해제
- 검색 변경 시 선택 상태 유지
- 검색 결과 수와 선택 수 표시

## 10. 개발 방식

본 기능은 BIM 모델의 반복적인 그룹 검토 업무를
빠르고 일관되게 수행하기 위해 개발했습니다.

업무 요구사항, 그룹 분류 방식, 검색 조건,
중첩 그룹 처리 기준 및 검증 방법은 직접 정의했습니다.

C#과 Revit API 구현에는 생성형 AI를 개발 보조 도구로 활용했으며,
생성된 코드는 실제 Revit 모델에서 반복적으로 테스트했습니다.

다음 과정을 통해 기능을 개선했습니다.

```text
그룹 검토 업무 분석
→ 필요한 검색 및 선택 방식 정의
→ 생성형 AI를 활용한 코드 구현
→ 실제 모델에서 실행
→ 그룹 누락 및 중첩 그룹 처리 확인
→ 검색과 선택 상태 오류 검토
→ 요구사항 수정
→ 재검증
```

## 12. 현재 한계

- 모델 그룹만 처리하며 상세 그룹은 대상에서 제외합니다.
- 링크 모델 내부의 그룹은 직접 처리하지 않습니다.
- 그룹의 직접 레벨을 찾지 못하면 위치 높이로 층을 추정합니다.
- 매우 많은 그룹과 구성요소가 있는 모델에서는 처리 시간이 증가할 수 있습니다.
- 그룹 구성요소 중 현재 뷰에서 숨김 제어가 불가능한 요소는 제외됩니다.
- 검색 결과의 정렬은 그룹 유형명을 기준으로 합니다.

## 14. 공개 범위

본 문서와 소스 코드는 포트폴리오 목적으로 재구성했습니다.

실제 회사명, 현장명, 프로젝트 모델, 내부 업무 기준,
전용 패밀리 및 설정 데이터는 포함하지 않습니다.
