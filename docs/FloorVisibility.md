# 층별 부재 보기

## 1. 기능 개요

Revit 모델에서 사용자가 선택한 층과 카테고리에 해당하는 부재만
활성 뷰에 임시로 표시하는 기능입니다.

여러 층과 여러 카테고리를 동시에 선택할 수 있으며,
마지막으로 선택한 조건은 저장되어 다음 실행 시 자동으로 불러옵니다.

본 기능은 모델 요소를 삭제하거나 영구적으로 숨기지 않고,
Revit의 임시 숨기기·분리 기능을 활용하여 표시 상태만 변경합니다.

---

## 2. 개발 배경

구조 BIM 모델을 검토할 때 특정 층의 바닥, 벽, 보 등만 확인하려면
사용자가 직접 요소를 선택하거나 뷰 설정을 반복적으로 변경해야 했습니다.

프로젝트 규모가 커질수록 다음과 같은 문제가 발생했습니다.

- 원하는 층의 부재를 일일이 선택해야 함
- 바닥, 벽, 구조 프레임 등 카테고리별 반복 선택 필요
- 여러 층을 동시에 비교하기 어려움
- 검토 후 기존 표시 상태로 되돌리는 과정이 번거로움
- 동일한 검토 조건을 매번 다시 선택해야 함

이러한 반복 작업을 줄이기 위해
층과 카테고리를 선택하여 관련 부재만 표시하는 기능을 구성했습니다.

---

## 3. 주요 기능

### 3.1 복수 층 선택

한 개 이상의 층을 동시에 선택할 수 있습니다.

예시:

- 지하 2층과 지하 1층 동시 선택
- 1층부터 3층까지 동시 선택
- 기준층 여러 개 비교

### 3.2 복수 카테고리 선택

현재 Revit 문서에 존재하는 모델 카테고리를 수집하여
사용자가 표시할 대상을 직접 선택할 수 있습니다.

기본 선택 카테고리는 다음과 같습니다.

- 바닥
- 구조 프레임
- 벽

### 3.3 이전 선택 기억

마지막으로 적용한 층과 카테고리 이름을 사용자 설정 파일에 저장합니다.

기능을 다시 실행하면 이전 선택 상태를 자동으로 불러오므로
반복적인 검토 작업을 빠르게 이어갈 수 있습니다.

### 3.4 임시 분리 표시

선택 조건에 해당하는 요소를 수집한 뒤
Revit의 임시 분리 기능으로 해당 요소만 표시합니다.

모델 요소의 영구적인 가시성 설정이나 숨김 상태는 변경하지 않습니다.

### 3.5 전체 원복

`전체 보이기 · 원복` 버튼을 누르면
이 기능에서 적용한 임시 숨기기·분리 상태를 해제합니다.

기존에 사용자가 설정한 영구 숨김 상태는 변경하지 않습니다.

### 3.6 예외 상황 안내

다음 상황에서는 사용자에게 안내 메시지를 표시하고 실행을 중단합니다.

- 열려 있는 Revit 문서가 없는 경우
- 활성 뷰가 없는 경우
- 뷰 템플릿에서 실행한 경우
- 일람표 또는 시트 뷰에서 실행한 경우
- 문서에서 레벨을 찾지 못한 경우
- 표시 가능한 모델 카테고리가 없는 경우
- 층 또는 카테고리를 선택하지 않은 경우
- 선택 조건에 해당하는 요소가 없는 경우

## 4. 처리 흐름

```text
기능 실행
→ 활성 Revit 문서 및 뷰 확인
→ 문서의 레벨 목록 수집
→ 모델 카테고리 및 요소 수 집계
→ 이전 선택 설정 불러오기
→ 층·카테고리 선택창 표시
→ 선택 조건에 해당하는 요소 탐색
→ 임시 분리 기능으로 대상 요소 표시
→ 선택 조건 저장
