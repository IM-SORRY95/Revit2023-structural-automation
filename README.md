# Revit 2023 구조 BIM 자동화

건축 구조 BIM 실무에서 발생하는 반복 작업을 개선하기 위해  
생성형 AI와 Revit API를 활용하여 구현한 업무 자동화 프로젝트입니다.
  
> BIM 실무자가 업무 기준을 정의하고 생성형 AI를 활용하여  
> 자동화 기능을 구현·검증·개선한 과정을 정리한 포트폴리오입니다.

---

## 프로젝트 목적

구조 BIM 모델에서 반복적으로 수행되는 다음 업무를  
보다 빠르고 일관되게 처리하는 것을 목적으로 합니다.

- 구조 모델 가시성 제어
- 층 및 그룹별 부재 검토
- 가설 부재 자동 모델링
- 모델 정보 및 유형명 검토
- 반복적인 작업 기준의 자동화
- 사용자 선택값과 검토 조건 저장

---

## 등록된 기능

### 1. 층별 부재 보기

사용자가 선택한 층과 카테고리에 해당하는 모델 요소만  
현재 Revit 뷰에 임시로 표시하는 기능입니다.

#### 주요 기능

- 여러 층 동시 선택
- 여러 모델 카테고리 동시 선택
- 이전 선택 조건 자동 불러오기
- 선택 요소 임시 분리
- 전체 표시 상태 원복
- 직접 레벨이 없는 요소의 위치 기반 층 판정
- 지원하지 않는 뷰와 잘못된 선택 조건 사전 검증

#### 관련 자료

- [층별 부재 보기 상세 설명](docs/FloorVisibility.md)
- [실행 명령 코드](src/FloorVisibility/FloorCategoryVisibilityCommand.cs)
- [요소 판정 및 표시 서비스](src/FloorVisibility/FloorCategoryVisibilityService.cs)
- [층·카테고리 선택 옵션창](src/FloorVisibility/FloorCategoryVisibilityForm.cs)

## 추가 예정 기능

### 그룹별 부재 보기

- 모델 그룹 목록 수집
- 여러 그룹 동시 선택
- 선택 그룹 표시 및 숨김
- 표시 상태 원복

### 잭서포트 자동 생성

- 구조 부재 및 하부 지지 조건 분석
- 부재별 배치 기준과 예외조건 적용
- 잭서포트 패밀리 자동 생성
- 최하층과 일반층 분류
- 높이별 색상 및 수량 검토

### 구조 모델 검토

- 지상·지하·전체 부재 보기
- 벽 상·하단 레벨 정보 확인
- 유형명 및 표준부재명 누락 검토

## 개발 방식

본 프로젝트는 BIM 실무에서 발견한 반복 업무를 개선하기 위해 시작했습니다.

업무 규칙, 기능 요구사항, 사용자 흐름, 예외조건 및 검증 기준은  
실제 BIM 업무를 바탕으로 직접 정의했습니다.

C#과 Revit API 구현에는 생성형 AI를 개발 보조 도구로 활용했으며,  
생성된 코드를 그대로 사용하는 것이 아니라 다음 과정을 반복했습니다.

```text
업무 문제 정의
→ 자동화 요구사항 작성
→ 생성형 AI를 활용한 코드 구현
→ 실제 Revit 모델에서 실행
→ 오류 및 예외 사례 확인
→ 판정 조건과 요구사항 수정
→ 재검증
→ 사용자 적용 및 피드백 반영
