# Revit 구조 BIM 자동화

건축 구조 BIM 실무에서 발생하는 반복 작업을 개선하기 위해  
생성형 AI와 Revit API를 활용하여 구현한 업무 자동화 프로젝트입니다.

## 프로젝트 목적

구조 BIM 모델의 반복적인 검토, 객체 표시, 매개변수 확인 및  
가설 부재 모델링 업무를 보다 빠르고 일관되게 처리하는 것을 목적으로 합니다.

## 주요 기능

### 잭서포트 자동 생성

- 구조 부재와 하부 지지 조건 분석
- 부재별 배치 기준 및 예외조건 적용
- 잭서포트 패밀리 자동 생성
- 최하층과 일반층 자동 분류
- 높이별 색상 및 수량 검토

### 층별 부재 보기

- 선택한 층의 구조 부재만 표시
- 카테고리별 표시 대상 선택
- 기존 표시 상태 복원

### 그룹별 부재 보기

- 선택한 그룹의 부재 표시 및 숨김
- 여러 그룹 동시 선택
- 기존 뷰 상태 복원

### 구조 모델 검토

- 지상·지하 구조 부재 구분
- 벽 상·하단 레벨 정보 검토
- 유형명 및 표준부재명 누락 확인

## 담당 역할

- 기존 BIM 업무 프로세스 분석
- 자동화 대상 선정
- 기능별 업무 규칙 및 예외조건 정의
- 생성형 AI를 활용한 C#·Revit API 구현
- 실제 Revit 모델 기반 기능 테스트
- 오작동 사례 분석 및 수정 요구사항 구체화
- 사용자 작업 흐름 및 결과 검토 방식 개선

## 개발 방식

본 프로젝트는 전문 소프트웨어 개발을 목적으로 시작한 프로젝트가 아니라,  
BIM 실무 과정에서 발견한 반복 업무를 개선하기 위해 진행했습니다.

업무 규칙, 기능 요구사항, 예외조건 및 검증 기준을 직접 정의했으며,  
C#과 Revit API 구현에는 생성형 AI를 개발 보조 도구로 활용했습니다.

생성된 코드는 실제 Revit 모델에서 반복적으로 테스트하고,  
오류와 예외 사례를 분석하여 실무에 적용할 수 있도록 개선했습니다.

## 개발 환경

- Autodesk Revit 2023
- Revit API
- C#
- .NET Framework 4.8
- Visual Studio
- Generative AI

## 주요 성과

- 잭서포트 모델링 작업 약 4시간에서 약 10분으로 단축
- 반복적인 구조 모델 검토 작업 자동화
- 작업자별 판단 차이를 줄이기 위한 업무 기준 구조화
- 실제 사용자 피드백을 반영한 기능 개선 및 배포
