# Revit 2023 구조 BIM 자동화

건축 구조 BIM 실무에서 발생하는 반복 작업을 개선하기 위해  
생성형 AI와 Revit API를 활용하여 구현한 업무 자동화 프로젝트입니다.

> 본 저장소는 전문 소프트웨어 개발자 포트폴리오가 아니라,  
> BIM 실무자가 업무 기준을 정의하고 생성형 AI를 활용하여  
> 자동화 기능을 구현·검증·개선한 과정을 정리한 포트폴리오입니다.

---

## 프로젝트 목적

구조 BIM 모델에서 반복적으로 수행되는 다음 업무를  
보다 빠르고 일관되게 처리하는 것을 목적으로 합니다.

- 구조 모델 가시성 제어
- 층 및 그룹별 부재 검토
- 가설 부재 자동 모델링
- 모델 정보 및 유형명 검토
- 반복적인 작업 기준 자동화
- 사용자 선택값과 검토 조건 저장

---

## 등록된 기능

### 1. 층별 부재 보기

사용자가 선택한 층과 카테고리에 해당하는 모델 요소만  
현재 Revit 뷰에 임시로 표시하는 기능입니다.

#### 주요 기능

- 여러 층 동시 선택
- 여러 모델 카테고리 동시 선택
- 이전 선택 조건 자동 불러오기
- 선택 요소 임시 분리
- 전체 표시 상태 원복
- 직접 레벨이 없는 요소의 위치 기반 층 판정
- 지원하지 않는 뷰와 잘못된 선택 조건 사전 검증

#### 관련 자료

### 2. 그룹별 부재 보기

현재 Revit 모델에 배치된 모델 그룹을 유형별로 조회하고,  
사용자가 선택한 그룹과 해당 그룹의 구성요소만 현재 뷰에  
임시로 표시하는 기능입니다.

#### 주요 기능

- 모델 그룹 유형별 목록 구성
- 동일 그룹 유형의 인스턴스 수 집계
- 그룹이 배치된 층 정보 요약
- 여러 그룹 유형 동시 선택
- 그룹 유형명과 층 정보를 이용한 검색
- 검색 결과가 변경되어도 기존 선택 상태 유지
- 검색 결과 전체 선택
- 전체 선택 해제
- 중첩 그룹 및 중첩 구성요소 탐색
- 중복 요소 처리 방지
- 선택 그룹 임시 분리
- 전체 표시 상태 원복
- 지원하지 않는 뷰와 잘못된 선택 조건 사전 검증

#### 관련 자료

- [그룹별 부재 보기 상세 설명](docs/GroupVisibility.md)

## 개발 방식

본 프로젝트는 BIM 실무에서 발견한 반복 업무를 개선하기 위해 시작했습니다.

업무 규칙, 기능 요구사항, 사용자 흐름, 예외조건 및 검증 기준은  
실제 BIM 업무를 바탕으로 직접 정의했습니다.

C#과 Revit API 구현에는 생성형 AI를 개발 보조 도구로 활용했으며,  
생성된 코드를 그대로 사용하는 것이 아니라 다음 과정을 반복했습니다.

```text
업무 문제 정의
→ 자동화 요구사항 작성
→ 생성형 AI를 활용한 코드 구현
→ 실제 Revit 모델에서 실행
→ 오류 및 예외 사례 확인
→ 판정 조건과 요구사항 수정
→ 재검증
→ 사용자 적용 및 피드백 반영
```

## 주요 성과

- 반복적인 구조 모델 검토 작업 자동화
- 여러 층과 카테고리의 부재를 빠르게 분리 표시
- 여러 모델 그룹과 구성요소를 검색하여 동시 검토
- 작업자가 반복 입력하던 층·카테고리 선택 조건 저장
- 검색 조건이 바뀌어도 그룹 선택 상태 유지
- 작업자별 검토 방식 차이를 줄이기 위한 기준 구조화
- 실제 Revit 모델 테스트를 통한 예외조건 개선
- 생성형 AI를 활용한 BIM 실무 자동화 가능성 검증

잭서포트 자동 생성 기능은 기존 약 4시간의 수작업을  
약 10분 수준으로 단축하는 것을 목표로 실무 적용했습니다.

BIM 자동화 기능의 업무 분석, 구현 방식 및 검증 과정을 보여주기 위한  
포트폴리오용 소스 코드입니다.

공개 대상에서 제외되어 저장소의 코드만으로 바로 실행되지 않을 수 있습니다.
